# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-07-27

### Added

- One-screen local PDF/text file workflow with one dominant action.
- Deterministic proposal classification and addendum identifier extraction.
- Source-linked `ACKNOWLEDGED` and `REVIEW` results.
- Downloadable Markdown evidence report.
- Friendly bounded-input and unreadable-document recovery.
- Automatic high-contrast light and dark appearance.
- Phone, tablet, and desktop responsive behavior.
- Vitest module coverage and Playwright E2E, PDF, accessibility, keyboard, failure, and visual
  matrix coverage.
- Open-source governance, security, architecture, product, completion, and continuation
  documentation.
